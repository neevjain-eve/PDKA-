🔧 OneDrive Setup Guide
Follow these steps once. Takes about 5 minutes.
1Open Azure Portal
Go to portal.azure.com and sign in with your Microsoft / Office 365 account.
2Register New App
Search for App registrations → Click + New registration
• Name: Agreement Tracker
• Account types: Accounts in any organizational directory and personal Microsoft accounts
• Redirect URI type: Single-page application (SPA)
• Redirect URI: http://localhost:8080/agreement-tracker.html
→ Click Register
3Add OneDrive Permission
In your new app → API permissions → Add a permission
→ Microsoft Graph → Delegated permissions → search Files.ReadWrite → Add
→ Click Grant admin consent (or ask your IT admin)
4Copy your Client ID
On the app's Overview page, copy the Application (client) ID
It looks like: a1b2c3d4-xxxx-xxxx-xxxx-xxxxxxxxxxxx
5Start the Local Server
Double-click start-server.bat (in the same folder as this file).
Then open http://localhost:8080/agreement-tracker.html in your browser.
⚠️ Important: The app must be opened via http://localhost:8080 (not as a local file) for OneDrive login to work. The start-server.bat file handles this automatically.
